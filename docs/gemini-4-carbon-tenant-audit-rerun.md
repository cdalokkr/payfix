### Architectural Diagnosis & Safety Posture

Before applying changes, two critical PostgreSQL internals govern this design:

1. **Hard `public` Schema Isolation:** All DDL below sets `LOCAL search_path = pg_catalog` inside transactions. Every object reference is strictly schema-qualified to `tenant_primary` and `tenant_interspace`. It is syntactically impossible for these migrations to create or mutate objects in `public`.
2. **PostgreSQL `CREATE TABLE ... (LIKE ... INCLUDING ALL)` Caveats:**
   * **Foreign Keys are omitted:** PostgreSQL never clones `FOREIGN KEY` constraints (`contype = 'f'`) via `LIKE ... INCLUDING ALL`. They must be applied in a second pass scoped strictly to `<target_schema>.<referenced_table>`.
   * **Sequence Default Leakage (`SERIAL` trap):** If any table in `tenant_primary` uses a legacy `SERIAL` default (`nextval('tenant_primary.<table>_id_seq')`), `INCLUDING ALL` copies that exact `DEFAULT` expression, causing new tenants to share `tenant_primary`'s sequence. Using `GENERATED BY DEFAULT AS IDENTITY` or `pg_catalog.gen_random_uuid()` avoids this, and our upgraded `provisioning.ts` also includes an automatic sequence-isolation sanitizer.

### Deliverable 1: PostgreSQL DDL (`tenant_primary` & `tenant_interspace` ONLY)

This idempotent migration inspects `<schema>.employees(id)` to match its exact key type (`UUID`, `BIGINT`, or `INTEGER`), aligns all 6 new tables across `tenant_primary` and `tenant_interspace`, enforces intra-schema foreign keys, and builds performance indexes—**without touching `public`**.

-- SAFETY LOCK: Zero access or fallback to `public` schema.

SET LOCAL statement_timeout = '60s';

  v_emp_id_type TEXT;
  v_pk_col_ddl TEXT;

  FOREACH v_schema IN ARRAY v_target_schemas LOOP
    -- Guardrail: Never allow execution against public or system schemas

      RAISE EXCEPTION 'SAFETY ABORT: Refusing to execute tenant migration against schema "%"', v_schema;
    END IF;

      FROM pg_catalog.pg_attribute a
      JOIN pg_catalog.pg_class c ON c.oid = a.attrelid
      JOIN pg_catalog.pg_namespace n ON n.oid = c.relnamespace
     WHERE n.nspname = v_schema

       AND a.attname = 'id'
       AND a.attnum > 0
       AND NOT a.attisdropped;
